# PRD: YouTube Next Content

## 목표
내 유튜브 채널이 어떤 콘텐츠를 하는지 분석하고, 지금 인기 급상승 중인 영상과 비교해 "다음에 만들 콘텐츠"를 추천받는다.

## 사용자
- 혼자 채널을 운영하는 유튜버 1명 (본인). 로그인·다중 사용자 없음.

## 핵심 기능
1. **내 채널 분석** — 채널 ID(`UC...`) 또는 핸들(`@...`)을 입력하면 최근 업로드 영상(최대 20개)의 제목·태그·카테고리·조회수를 가져와 요약한다.
   - 표시 항목: 채널명, 구독자 수, 주력 카테고리, 자주 쓰는 키워드/태그 상위 10개, 평균 조회수, 조회수 상위 영상 3개
2. **인기 급상승 영상 수집** — YouTube 공식 인기 급상승 차트(`videos.list?chart=mostPopular`, 지역 `KR`)에서 내 채널의 주력 카테고리 영상 최대 20개를 가져온다.
   - 해당 카테고리가 차트를 지원하지 않으면 카테고리 필터 없이 전체 인기 급상승으로 대체하고, 대체했다는 사실을 화면에 표시한다.
3. **다음 콘텐츠 추천** — 1·2의 데이터를 Claude API에 넘겨 다음 콘텐츠 3~5개를 구조화된 JSON으로 받는다.
   - 추천 1개 = 제목안, 한 줄 컨셉, 추천 이유(내 채널 강점 + 참고한 인기 영상), 참고 인기 영상 ID 목록
   - 채널 전체에 대한 분석 코멘트(2~4문장)도 함께 받는다.
   - 쇼츠/롱폼은 따로 구분하지 않는다. 추천의 `concept`에 형식(쇼츠/롱폼)을 함께 제안하게 한다.
4. **2단계 로딩** — 채널 요약과 인기 급상승 목록(1~2초)을 먼저 보여주고, 추천(10~40초)은 이어서 표시한다. 추천을 기다리는 동안 "추천 생성 중… 보통 20~30초" 문구를 보여준다.
5. **다른 추천 받기** — 같은 채널 데이터로 추천만 다시 생성한다 (YouTube 재조회 없음). 추천이 실패하면 같은 버튼이 "추천 다시 시도"가 된다.
6. **편의 기능** — `.env`의 `NEXT_PUBLIC_DEFAULT_CHANNEL`로 입력창을 미리 채운다. 추천 제목 옆에 [복사] 버튼, 참고 인기 영상은 YouTube 링크(새 탭)로 연결한다.

## 유저 플로우
```
페이지 열기 → (기본값 채워진) 입력창 → [분석하기]
  → 형식 오류? → 입력창 아래 안내
  → 채널 없음 / 영상 0개? → 에러 문구
  → ★ 내 채널 요약 + 인기 급상승 목록 표시
  → 추천 생성 중… → 실패? → 요약 유지 + [추천 다시 시도]
  → ★ 분석 코멘트 + 추천 카드 3~5개
  → [복사] / 참고 영상 열기 / [다른 추천 받기]
```

## MVP 제외 사항
- 로그인/OAuth, YouTube Analytics API(시청 지속 시간, 수익 등 비공개 지표)
- 분석 결과 저장, 히스토리, DB
- `search.list` 기반 키워드 검색 (쿼터 100 units/회로 비쌈)
- 다국가 지원 (지역은 `KR` 고정)
- 다른 채널(경쟁 채널) 비교 분석
- 쇼츠/롱폼 자동 분류
- 배포 (로컬 `npm run dev`로만 사용)
